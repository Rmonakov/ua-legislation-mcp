- Навичка `npa-ofitsiini-dzherela` тепер однаково підходить для Claude і ChatGPT: нагадування про запуск сервера описує обидва варіанти.

## 0.1.1 — 2026-11-24

Виправлення за результатами першої перевірки на справжньому порталі.

- Claude Desktop передавав незаповнене поле «Тека кешу» як шаблон `${user_config.cache_dir}` — кеш не працював. Тепер такі значення ігноруються, а недоступна для запису тека замінюється тимчасовою.
- Перелік документів для пошуку використовується з пам'яті, навіть якщо його не вдалося зберегти; після невдалого завантаження повтор — не раніше ніж за 30 хвилин.
- Умовна дата 01.01.3000 у картці показується як «дата набрання чинності ще не визначена».
- Підстави редакцій показуються як «№ 4196-IX (nreg 4196-20)».
- Прибрано рядок «дата набрання чинності поточною редакцією»: поле картки означає інше.
- Стрічка оновлень: код документа береться з посилання (колонка card містить опис).
- Назва розширення латиницею, щоб назви інструментів у клієнтах були читабельні.
- Навичка для Claude `npa-ofitsiini-dzherela` (тека `skills/`), архів навички додається до кожного релізу.

## 0.1.0 — 2026-11-24

Перша версія.

- Інструменти: `search_acts`, `get_act_card`, `get_act_text` (стаття, пошук, зміст, частини), `check_act_editions`, `list_recent_updates`, `service_status`; `search` / `fetch` для ChatGPT.
- Режими: stdio (локальні клієнти) і Streamable HTTP із секретним шляхом (ChatGPT, claude.ai).
- Доступ лише через портал відкритих даних `data.rada.gov.ua`: `User-Agent: OpenData`, пауза ≥5 с, добові ліміти, кеш.
- Пакет `.mcpb` для Claude Desktop.
